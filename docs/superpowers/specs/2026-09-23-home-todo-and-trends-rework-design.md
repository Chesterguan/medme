# 首页待办 + 自测按周折叠 + 添加里记数 + 趋势重整 —— 设计

**日期** 2026-09-23 · **状态** 待用户过目 · **上游** 减法(PR #229)之后
**方案页** https://claude.ai/artifact/XR4NmY7A5jYY4D16YHnmMa(第三、四、六、九节)· 档案推开另开 spec

## 为什么

用户 2026-09-23:自己记的东西把真事件淹了;只有一个数不叫趋势;点类别下面不跟着变;趋势和病历重合;首页应该是「接下来要干什么」;记录一下不该在趋势里。原则:**每页只答一个问题**——病历答「接下来要干什么、最近发生了什么」,趋势答「哪个指标在变、往哪走」,添加答「把东西放进来」。

## 一、首页「待办」块

在成员行和两颗按钮之下、时间线之上。**没有一条时就整块不画**(不制造不存在的待办)。条目按紧急度排,每条一行:标题 + 一句依据 + `›`。来源与顺序:

| # | 条目 | 来源(全部已有数据) | 点进去 |
|---|---|---|---|
| 1 | 「N 份还没核对」+「扫描件,识别出的字有几处不确定」 | 现有 `PendingReviewBanner` 原样并入 | 滚到还没核对区 |
| 2 | 「正在后台识别 N 份 …」 | 现有 `ImportQueueCard` 原样并入 | — |
| 3 | 档案到期:`<提醒 text>` + 「超期 N 天 / 该查了」+ 依据(包里的 `basis`/`source` 一句话) | 已开启档案的 `reminders` 节(`state` = overdue / never / pending 三档,pending 只显示不算日期,与档案页一致) | 该档案页对应的提醒行 |
| 4 | 「最近 30 天有 N 项偏高 / 偏低」 | `recent_changes` 里 30 天内标记 H/L 的条数(自测的不算) | 「给医生看」 |

- 顺序 = 表里的顺序;第 3 类内部按 overdue 天数降序、never 在 overdue 之前(沿用档案页排序)。
- 第 4 条只在 N ≥ 1 时出现;app 里没有「上次给医生看的时间」,所以**不说「还没给医生看过」**(不编)。
- 视觉:减法规则——一张白卡,行间细线,第 1 条琥珀状态词、第 3 条逾期用 `high`、其余 `ink`;不加图标。

## 二、时间线:自测记录按周折成一行

- 时间线里的 `self_measurement` 文档(血压 / 心率 / 体重 / 体温 / 血糖)不再一条一行,**按自然周(周一–周日)折成一行**:标题 `自测 · 4 月 27 日 – 5 月 3 日`,副行按指标列 `血压 5 次 118–132 / 74–80 · 心率 5 次 66–74 · 血糖 3 次 6.1–6.8`(次数 + 最小–最大;血压是收缩/舒张各自的范围)。
- 点开:展开这一周每一条(日期 + 值),每条可点进原件、可左滑删(沿用子文档行)。
- 位置:仍在所属月份的卡里,按周的最后一天参与倒序排。跨月的周归到周一所在的月。
- 笔记(`note`)**不动**(一天一条是常态,用户没提)。
- 实现落在 Rust 投影:`TimelineGroupDto` 新增 `SelfWeek { week_start, week_end, docs, summary: [{analyte_key, label, count, min, max, unit}] }`,由现有 `timeline()` + 自测文档的结构化值聚合;Dart 只渲染。**不在 Dart 里凑**——值在文档结构里,列表 DTO 没有。
- 「示例」标、还没核对的自测(理论上不存在,自测不经 OCR)不受影响。

- 趋势页的 `RecordEntryCard`(「记录一下」)删除;「给医生看」里的「加一条」(笔记)保留——那是在写「想问医生的」,不是记数。
- 存完仍走现有刷新链(BUG-4 那组测试):首页时间线与趋势都当场重拉。

## 四、趋势重整

1. **只有 ≥ 2 次有日期的点才是趋势**。`trendVisible` 先按 `pts.length >= 2` 分成两组:趋势组进列表;单次组折到页尾一行「只测过一次的 N 项 ›」,展开后每项一行 `LabLine`(名称 · 日期 · 值 · 状态词,无折线)。N = 0 时这一行不画。
2. **类别 chip 筛整页**:选中的 `panel` 同时作用于关键化验卡与折线列表(现在只作用于折线卡);「只看异常」改成独立开关 chip,排在类别 chip 之后,与类别叠加(不再互相让位)。搜索仍然覆盖两者。
3. **关键化验卡与折线卡合并成一个列表**:一行一个指标 = 名称 + 迷你折线(78×24,`TrendChart(height: 24, animate: false)`,只画线和点,不画参考带)+ 最近值 + 状态词 + 刻度条;点一行原地展开 96 高的大图(现在 `SeriesCard` 的展开区)。也就是说 `KeyLabsSnapshot` 与 `SeriesCard` 合成一个 `TrendRow`。默认展开态:全部收起。
4. 删 `RecentVisitsCard`(病历页有)、删 `RecordEntryCard`(见三);`UnderstandBanner` 已删;`ProvenanceFooter` 留页尾。
5. 病程档案入口行不动(档案推开另 spec)。

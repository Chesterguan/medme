# 进阶版 · 总纲(2026-09-11)

> 状态:已与创始人逐条拍板(会话 2026-09-11)。本文只记**决定与拆分**,细节在各子项目 spec。
> 这是对「纯本地、无账号、不上云」路线的**有意翻案**,须新 ADR(0010)supersede 旧决定,并同步隐私政策(CLAUDE.md 硬规矩 4)。

## 为什么

- 纯本地无账号不适合商业化,也接不上 Prometheno 生态。
- 正则抽取在 683 份真实化验单上端到端 28%,且会「安静伪造合理值」(WORKLIST P0);行对齐路线 2026-08-14 已试死。云 LLM 是唯一能解的路。
- 老产品偏常见病记录;进阶版要承载**纵向病程**(慢病/罕见病)。

## 已拍板的决定

| 决定 | 内容 |
|---|---|
| 形态 | **直接改现有 app**,不分两个产品;手机端是入口;**桌面端先不管**(vault 与桌面逐字节兼容的约束解除) |
| 抽取 | **本地 OCR 只做脱敏与定位,识别交给云 LLM。** 生产模型 DeepSeek(文本 `deepseek-v4-flash`,图片 `deepseek-v4-flash-vision-exp`);够用就行 |
| Key | **只走我们的代理**,订阅计费;不做 BYOK |
| 脱敏 | 中国单子对照 HIPAA 18 项的清单落成 fixture + 测试;**年龄保留**;**日期按档案统一偏移 ±90 天**(不按文档);对外话术=「本地脱敏后送云端」,不说「不出手机」 |
| 加密 | (a)+(c):口令派生密钥 + 恢复码兜底 + 旧设备授权新设备 + 系统钥匙串;**不做密钥代管**;云端只存密文 |
| 云端存什么 | 加密后的**整个保险箱**(原件 + 日志)+ 包好的密钥 + 账号业务数据;LLM 中转不落盘。存储成本每用户每月按分算 |
| 登录 | 微信/支付宝优先但**今天接不了**(要营业执照);先做**手机号(阿里云 PNVS,个人可用)+ Apple**;登录方式与账号 id 解耦,接口预留 |
| 托管 | 一个原语「授权」:档案 → 账号 → 权限(主人/可编辑/只读)→ 有效期。家属=可编辑永久;**医生=只读 15 天**;机构=只读到期(以后) |
| Profile | **服务端 skill/prompt 框架**:一病一份 skill(prompt + 固定输出 schema),app 一个渲染引擎,改 prompt 不发版。先通用 + 一个病 |
| 对外定位 | 「我们保管箱子,不保管钥匙;数据只在用户按下同意的那一刻流动」。没有数据集,只有经同意的数据流 |

## 拆分与顺序

| # | 子项目 | spec | 依赖 |
|---|---|---|---|
| A | 脱敏 + 云抽取管线 | `2026-09-11-deid-cloud-extraction-design.md` | 无(评测期用临时 token 走代理) |

**A 与 B 并行。** 接缝只有一处:A 的代理端点 `POST /v1/extract` 最终由 B 的账号 token 鉴权;A 开发期用静态 token(沿用 claim-signer 的 `MEDME_UPLOAD_TOKEN` 模式)。

## 横切任务(随 A/B 一起交付,不单列子项目)

1. ADR 0010:云 LLM 抽取 + 账号,supersede ADR 0005/0006 里「识别全在端上」的部分与 memory 里「不上云」决定。
2. 隐私政策(`../Medme-ghpages/privacy.html`):存储 E2E;识别时本地脱敏后送境内 LLM;账号数据;授权与撤销的真实语义(撤销后不再能获取新内容)。
3. 官网话术:「零服务器」→「密文后端」;已在 [[landing-messaging-2026-07]] 松绑,落地。
4. 导入时压图:长边 2000px、JPEG q85,不留未压缩原图(创始人默认同意,可翻)。

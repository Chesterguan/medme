**稿子** https://claude.ai/artifact/5vC4xPqUoL5eJimz3cmzvV(源:`2026-09-22-subtraction-mockup.html`,图片占位 `{{IMG*}}`/`{{LOGO}}` 未内嵌)

## 为什么

用户 2026-09-22:「视觉噪音太强,像 2020 年的小程序和政务软件,不够克制,有些加深颜色的部分并没有信息;每一页都应该去思考用户打开最想看到什么。」同意减法分析,要求学 Guava 的克制。看到稿子后:「舒服多了」;「没有用的就删掉,有需要再加」。

## 六条原则(取代 Stage 3 brief 里与之冲突的部分)

1. **一个品牌色**:医疗蓝只出现在主按钮、选中项、链接。渐变面、书脊、光泽块、光晕全部退场。
2. **颜色只说状态**:偏高橙 `high`、偏低蓝 `low`、危急红 `critical`、还没核对琥珀。**正常不上色,类别不上色。**
3. **状态 = 一个词 + 位置**:化验行右列是「偏高」两个字(上色、无底)+ 一条细刻度上的点;不再有整条左色带。**正常什么字都不加**(app 从不显示「正常」二字,`design_tokens_test.dart`/`mobile_ia_test.dart` 钉着)。
4. **白底黑字,只有一套浅色**:底 `#F6F8FA`,卡白 + 1px `line` 细边,无阴影;层级靠字号和留白。不做深色默认(老人/散光在纯黑底上会光晕,诊室都是亮的)。
5. **图标退到线性或不用**:有信息才出现,单色 `ink2`;稿子里没画的位置(主页病历行、给医生看的分节标题、趋势最近就诊行)直接删。
6. **首屏答一个问题**:病历答「有没有要我做的」,趋势答「哪个指标不对」,给医生看答「一页纸」。

## 逐屏

- **病历**:顶栏 logo + 「病历」,**不放搜索**(现在的「找一找」点了只说「还在做」——用户裁定删,Stage 2 搜索做出来再放回)。成员一行(名字 + 性别·年龄·N 份记录·最近就诊·日期 + ⌃⌄),「添加」实心药丸 + 「给医生看」描边药丸,「还没核对」琥珀横幅置顶,还没核对的卡片,然后按月分组:月份小标题 + **一张卡装整月的行**(细分隔线,无图标,无骑缝线)。
- **趋势**:病程档案 = 白卡一行(logo 30 + 标题 + 说明 + 「活动度(化验可算部分) 0 / 18」一行 + ›);「关键化验」小标题;文字 chip(选中 = 蓝描边 + sealInk 字);化验行新解剖;**「看懂」占位横幅删**(只有壳,和「找一找」同类);最近就诊行不带图标。
- **给医生看**:顺序改为 我最近的变化 → 医生可能要问的(过敏史 → 记录中出现的药物)→ 我想问医生的(紧挨底部按钮);每节 = 小标题 + 一张卡;底部一颗实心「出码给医生看」。

## 稿子与现状的三处有意偏差(不照稿子)

- 稿子给医生看那行「血压 心率 · 122/76 · 70/min · 正常」:app 里收缩压/舒张压/心率是三条独立化验行,且**不显示「正常」二字**——按现状,正常行只有刻度点。
- 稿子把还没核对的文档画在月份组里(「· 还没核对」):现状是独立卡片区在月份组上面,**结构不动**,只换样式。
- 稿子主按钮是 `seal #1789C1`:实现用 `sealInk #0E6285`——白字压 seal 只有 3.9:1,目标用户含老年人,`theme.dart` 早已定了填充按钮一律 sealInk(6.76:1)。

## 全 app 连带(稿子只画了三屏,原则管全 app)

- `HeroCard` 保留但改成**实色** `sealInk` 卡(代拍首页传 `proxyInk`),用在换新手机 s15、代拍交付 s14、代拍首页——那是这三屏「唯一的一块颜色面」,卡内白字一个不动。
- `MedPrimaryButton` 实色 sealInk;禁用态不变(`line2` 底 `ink2` 字,R29/R30)。
- `MedCard` 细边无阴影;**骑缝线(`perforated`)删**——没人读得出那排点在说「可溯源」。
- 光泽图标块 `GlossIconTile` → `MedIcon`(44 槽里一枚 22px `ink2` 线性图标)+ `MedAvatar`(圆底首字);`GlossCategory` 九档类别与 `categoryForDocType/VisitKind` 整个删。
- 首启场景:只留 104px logo,三个光泽块删。
- 底栏:阴影 → 顶部一道 `line`;未选中图标 `ink3`。
- `MedChip` 描边;`MedDemoPill`(零调用)删;`MedReadBanner` 删。
- 化验单表格(`report_content.dart`)与化验行同规则:无色条、状态词、正常不上色。
- 病程档案页(`profile_sections.dart`):行左 `line2` 竖条删,图标 → `MedIcon`,时间轴危急点用 `critical`。

## 不动的

文案(除用户点名删的「找一找」「找一找还在做」「看懂」+ 占位句)、信息结构、三道闸(文案闸 / 裸色闸 / 预算闸,预算闸改成「无渐变 + 每屏主按钮/主卡计数」)、字号(老人)、Manrope、logo、医疗蓝。

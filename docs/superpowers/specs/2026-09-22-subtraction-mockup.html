MedMe 减法稿

三屏「现在 → 减法」并排。白底黑字,只有一套浅色(不跟系统深色走)。原则借自 Guava:白卡浅底、一个品牌色、颜色只给状态、图标退到线性或不用、层级靠字号和留白。文案一字未动(仍是 Stage 1 定稿)。

一个品牌色:医疗蓝只出现在主按钮、选中项、链接。渐变面、书脊、光泽块全部退场。
颜色只说状态:偏高橙、偏低蓝、还没核对琥珀。正常不上色,类别不上色。
状态用字 + 位置:化验行右侧是「偏高」两个字加一条细刻度上的点,不再是整条左色带。
首屏答一个问题:病历答「有没有要我做的」,趋势答「哪个指标不对」,给医生看答「一页纸」。

出码给医生看
从 Guava 借的四点:① 一个品牌色 + 中性灰,状态色只有两三种;② 化验行的状态是「一个词 + 刻度上的点」,一眼能看位置;③ 卡片无阴影、细分隔线、圆角一致,层级全靠字号;④ 图标只在需要区分时出现,且是单色线性。
没照搬的:Guava 的顶栏是实色绿,我们保持白顶栏 + 蓝只给按钮,和 logo 更协调;Guava 每类器官一个彩色小图标,我们连这个也去掉(类别不上色)。
代码代价:Stage 3 的令牌都在,这次是删:渐变面 → 一个实色主按钮;光泽块 → 无图标;左色带 → 状态词 + 刻度点;正常不上色改回;阴影去掉。文案闸、裸色闸、预算闸照常挡。

# ADR 0013 · 底部四 tab:病程档案并入主界面,病种包按诊断自动出现

Status: Accepted · Date: 2026-10-23

**Amends**:[0012](0012-generic-chronic-profile-layer.md)、[0011](0011-disease-profile-skill-packages.md)(增补,不 supersede)

## Context

用户把 Epic 全量病历装到 iPhone 上试了结构化导入(#243)、时间线分档(#247)、通用病程档案层
(#248)之后,2026-10-23 的反馈原话:「依据没必要列出来,点的时候显示原件就好」「现在里面很多
东西不是现在的,过去吃过的药没必要显示」「把药单独加一个 tab 显示最近,医生可以搜过往,过敏也移
过去」「还是只有红斑狼疮的包,强行打开没有意义」「重新思考底部 tab」「太久远的化验不用展示」
「化验值没有折线图不容易看」。此前的结构是:趋势 tab 里一张入口卡 → 独立档案页 → 三 tab(现在 /
进程 / 依据),包要用户手动「开启」;趋势页的化验行从没放过真折线(78×24 的占位空着)。

## Decision

1. **底部四个 tab:病历 / 现在 / 用药 / 我。** 趋势 tab、病程档案入口卡、档案独立页、「进程」
   「依据」两个 tab、包的「开启 / 关闭」按钮全部取消。一个事实只在一个 tab 上有「家」:诊断与化验
   在「现在」,药与过敏在「用药」,原件在「病历」,别处只给跳转。
2. **「现在」只放此刻成立的东西,判定只看事实。** 诊断按最近出现日、化验按最近有日期的点,在
   `RECENT_DAYS = 365` 天内才进;更早的各收成一行。界面只说「N 份记录提到 · 最近 YYYY-MM」,
   不出现「活动 / 已解决 / 既往」。常量只在 Rust 定义一处,化验那一半经 FFI 下发给 Dart。
3. **病种包不再要用户开启,按诊断自动出现。** `package_applies`:任一诊断原文含包的
   `triggers.diagnosis_patterns`(第一次有读者),或归一后的 ICD 以 crate 常量
   `PACKAGE_ICD_PREFIXES`(sle → M32)开头。前缀放 crate 里是为了不重签包。出现的位置是包
   `manifest.family` 对应的族卡展开区;该族没有卡(诊断无码落在「未归类」)时独立一段排在族卡
   之后。`enable/disable` 事件保留给查看器 / 分享的单包路径,手机通用视图不读;术语覆盖层
   改成「装着就装上」(覆盖层只加不改,0011 决定 6)。
4. **「依据」是一次点击,不是一个 tab。** 任何带 `ev:` id 的值点一下进原件并高亮:一条直开,多条先
   弹层选。Rust 给的 `span` 是 needle 的 UTF-8 字节偏移、`quote` 常是整行,Dart 换成 UTF-16 下标
   后取包含它的那一处 quote——以前同一引文出现多次永远高亮第一处。
5. **「用药」的两段叫「最近的用药」(180 天内有记录、原文没写停)与「更早的用药」**,不叫「当前
   用药」:`MedSpan.status` 恒 active,不能暗示有效医嘱(应急卡早有这条禁令)。每味药带
   `first / change / stopped` 剂量链;过敏在同一本依据簿里引出处(物质串所在的那一行),所以也能
   点开原件。包的 `gc` 状态行不再替换通用层的用药行(0012 那条作废):药表与包段不在同一屏。
6. **英文过敏进 parser。** Epic 的「Allergies / Allergen | Reactions / • 物质  反应」表与「Allergies:
   A, B」行式,否定(No Known Allergies / NKDA / NKA / none)一张小表,独立于中文的否认 / 无逻辑;
   `extract_allergies_pairs` 改 pub,手机 crate 那份逐字副本删掉。
7. **「进程」的泳道并进病历页的筛选 chip**:住院 / 急诊本来就在,手术 / 影像 / 病理变成三颗文档类型
   chip(选中时把就诊组里和独立的这一类文档抽出来平铺);用药变化去了剂量链,诊断首次出现在诊断行。

## 考虑过的替代方案

- **保留「依据」tab、只把「现在」清一清**:被否——用户原话是「没必要列出来」;依据清单是「只输出
  原文逐字」的界面形态,点开原件同样兑现它,少一个 tab。
- **读 Epic Problem List 的 Resolved On 判「已解决」**:留作后续——要改 myEHR 适配器与
  `DiagnosisItem`,且只有 Epic 有;12 个月窗不需要出处,先用它。
- **包仍要用户开启,只是把按钮藏深一点**:被否——没有狼疮诊断的人开了也是空的,有的人不开就看不到;
  诊断本身就是最好的开关。
- **「现在」族卡只列药名、还是整行药表**:只列药名——药的家在「用药」,两处各说各的,医生看
  「我的心脏病」时知道在吃什么,要剂量去隔壁 tab。

## Consequences

- 0012 决定 1 的「三视图(现在 / 进程 / 依据)」、0011 决定 3 的「入口卡 → 独立页」、0011 决定 5 里
  `enable/disable` 作为**用户动作**的那层、0012 §4「包的 latest_dose 行替换通用层同类药」四句
  **不再成立**;两份 ADR 的决策骨架(签名包、引擎纯函数、零新事件、只分组不判断、常量表、内置包)
  一条不改。
- 零新事件、零新表、不改 `Extraction`、不重签包、不上云;`ProfileView` 多一个 `packages[]`
  (单包路径不序列化,两份 SLE golden 逐字节不变);`MedRow` 多 `drug_key / raw_names`。
- 埋点:`home_tab_selected` 的 `trends` 值到此为止,新的 `now / meds` 从这天起算;
  `trends_filter_used` 只会再发 `search`。不新增事件、不新增请求 → 隐私政策不动。
- 行为变化要说出来:原趋势页「只看非正常项」默认开着,现在「现在」列最近 12 个月全部序列,偏高 / 偏低
  靠行内标记。
- 已知缺口:Problem List `Resolved On`、Epic `Patient not taking`、中文诊断名 → ICD、行式过敏跨行
  续写(`Allergies: A, B-\n  C`)、tab 位置持久化、图片档依据画框、桌面 Tauri。
